# Sumerian Grammar Ticks

Notes and cheatsheets for Sumerian grammar + cuneiforms.
Also the place that swallowed *two-worlds*: speech as bone, vowels as number.

## Summary

Sumerian writes the world as signs and numbers. Speech here follows that:

- Consonants = content. The bone. What remains when you read *father*.
- Vowels = frequencies / numbers. Like Nanna written as **30**.
- Torah without niqqud is the same trick: skeleton first, breath later.
- Fast speech drops the consonants. Others hear only vowels. Slow down and the bone returns.
- Typed thought is a different world than spoken thought.

Moon: Sumerian moon is **Nanna / Suen** (later Akkadian **Sin**). The moon *goddess* beside him is **Ningal** (“Great Queen”). Selene is the Greek name for the same sky-object. See `nanna-ningal.md`.

- Vowels-as-number tick: replace spoken vowels with Hz / count, keep consonants
